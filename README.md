This application started out in life as a NeHe OpenGL tutorial contest entry for Halloween 2000 by Jim Strong and was titled "Xersist's Happy Halloween".  I converted the entry into a proper Windows screensaver and added a flying witch and a 3D skull with a nice texture map.  All the image and model assets were also converted into C/C++ include files so the separate images, audio, and model files would not have to distributed or installed.  There's just one .scr file.  To install it, just right-click the .scr file and select "Install".

To build the screensaver, open the Visual Studio Solution file and select "Build".
